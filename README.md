# CasinoBooking.com

Bilingual English/Greek luxury travel-concierge MVP built with TanStack Start, React, TypeScript and Tailwind CSS.

## Functional demo

Public resort discovery, country/search filters, travel services, validated enquiries with request/customer references, and a demo CRM with customers, requests, partner candidates, travel, commission examples, reports and settings. Enquiries and status changes live in memory only and disappear on refresh. Use fictional details; no bookings, messages, authentication or payments are performed.

Photography is illustrative and royalty-cleared. Property imagery awaits approval. Directory candidates are not confirmed partners; Hard Rock Athens is planned, not open. Privacy and terms are legal-review drafts. A manifest and home-screen icons provide mobile readiness; no offline service worker or native apps are provided.

## Before accepting real enquiries

Connect Lovable Cloud, implement authenticated customer/admin roles and least-privilege record access, define consent and retention/deletion procedures, verify provider agreements and contact channels, and complete legal review. Require HTTPS/TLS, administrator MFA, input validation, audit logging without sensitive data, and a reviewed backup/recovery process. No security guarantee is implied.

## Development

Install dependencies with `bun install`, run `bun run dev`, and run tests with `bun run test`.
